# Loan Risk Predictor Using Machine Learning

## Project Overview

Loan Risk Predictor is a machine learning project developed to predict whether a loan is likely to be classified as **PAIDOFF** or **COLLECTION** based on applicant and loan-related information.

The project helps financial institutions identify high-risk borrowers and make informed lending decisions using data-driven risk assessment techniques.

---

## Objectives

- Predict loan repayment outcomes using machine learning.
- Analyze historical loan data and identify risk patterns.
- Compare multiple classification algorithms.
- Improve loan risk assessment for financial institutions.

---

## Dataset Features

The dataset includes:

- Gender
- Marital Status
- Education
- Applicant Income
- Loan Amount
- Loan Term
- Credit History
- Property Area
- Coapplicant Income
